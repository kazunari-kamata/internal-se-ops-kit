# サービス要求・SLA/KPI管理

問い合わせ・サービス要求は、受付、分類、優先度、担当、期限、解決、利用者確認、ナレッジ化を記録します。SLAは合意した対応水準、KPIは運用改善の測定値です。

| 指標 | 算出例 | 用途 |
| --- | --- | --- |
| 初回応答時間 | 受付から初回応答まで | 受付体制の確認 |
| 解決時間 | 受付から解決確認まで | 滞留・依存関係の確認 |
| 期限内完了率 | 期限内完了件数 ÷ 対象件数 | 達成状況の確認 |
| バックログ | 未完了要求の件数と経過日数 | 優先度・要員調整 |

起点・終点、対象時間、除外条件、エスカレーションを定義し、未達は個人評価でなく手順・体制・自動化の改善材料として扱います。
